# VIRTUOS Configurator releases

Windows installers of the [VIRTUOS Configurator](https://projects.virtuos-app.workers.dev/product-configurator/)
desktop app. Download the latest `VIRTUOS-Configurator-Setup-<version>.exe` from
[Releases](https://github.com/arthovis-org/virtuos-configurator-releases/releases/latest);
installed copies update themselves from here.

The app's source is in a private repository; this one only holds its releases, published by
its `configurator-desktop` workflow.
